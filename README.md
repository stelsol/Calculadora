# 🧮 Calculadora

Projeto desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web, explorando conceitos de JavaScript, manipulação do DOM e criação de interfaces responsivas utilizando Bootstrap e Tailwind CSS.

## 🌐 Acesse o Projeto

Teste a aplicação através do link abaixo:

🔗 **Deploy:** https://stelsol.github.io/Calculadora/index.html

## 📌 Status

✅ Concluído — Projeto desenvolvido para fins de estudo e prática.

## 🚀 Tecnologias Utilizadas

- HTML5
- JavaScript
- Bootstrap
- Tailwind CSS

## 🎯 Objetivo do Projeto

Este projeto foi criado para fortalecer conceitos fundamentais do desenvolvimento Front-End, com foco em:

- Manipulação do DOM
- Eventos de clique
- Lógica de programação
- Operações matemáticas
- Interação com o usuário
- Estruturação de interfaces responsivas

## 📋 Funcionalidades

- Soma (+)
- Subtração (-)
- Multiplicação (×)
- Divisão (÷)
- Limpeza completa da tela
- Exclusão do último caractere
- Exibição dinâmica dos cálculos
- Interface responsiva para diferentes dispositivos

## 🛠️ Como Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/stelsol/Calculadora.git
```

2. Entre na pasta do projeto:

```bash
cd Calculadora
```

3. Abra o arquivo `index.html` em seu navegador.
